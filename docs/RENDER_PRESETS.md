## How each P1-a item lands

- **P1-a1 Upscaling / frame generation** — declared as the `d3d11_proxy` injection
  slot (not an INI key). The Windows build binds it through a D3D11 proxy-chain
  plugin; precedent verified Sept 2026: the open-source FSR3 frame-gen proxy for
  FO4 on engine build 1.10.163, and GamePlug-style FSR1/2/3 + DLSS + XeSS
  injection bridges. Address Library is a hard companion dep (see
  `docs/INTEGRATION_CHECKLIST.md`).
- **P1-a2 Lighting** — `lights.dynamic_per_frame` (24–48) + per-pixel lighting;
  the engine's per-frame dynamic light cap is the usual bottleneck for
  "GI-quality" interiors. The preset raises the cap per tier; true GI (SSGI/
  screen-space global illumination) ships via the RE/ENB slot.
- **P1-a3 Shadows** — cascade splits 2–4, distance 80–160 m, soft-shadow quality
  `fSoftShadowQuality` 1.6–2.4.
- **P1-a4 Volumetrics / atmosphere** — step count + scatter; `via:
  re_shade_or_enb` marks it as post-injection (the engine's native fog/volume
  is not steerable granularly).
- **P1-a5 Nature (grass/water/particles)** — `iMaxBladesPerBucket`, decal/frame
  caps.
- **P1-a6 Post & pacing** — bloom/chromatic/grain, FXAA only on the low tier;
  dynamic resolution clamps to the per-tier `target_ms` (the frame-watchdog
  from M3 is the enforcement point).
